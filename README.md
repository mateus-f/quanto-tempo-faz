**Uma calculadora simples e precisa que exibe a idade em anos, meses e dias a partir da data de nascimento informada.**

[🔗 Acesse a versão online](https://quanto-tempo-faz-eight.vercel.app/)

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio do Frontend Mentor. A aplicação recebe uma data de nascimento como entrada e calcula a idade exata com validações e layout responsivo. Também foi um exercício prático de desenvolvimento a partir de um design no Figma.

## 🧩 Funcionalidades

* 📅 Cálculo da idade em anos, meses e dias
* ❌ Mensagens de erro para datas inválidas
* 📲 Layout responsivo para diferentes dispositivos
* 🧠 Validação precisa de campos (dia, mês, ano)
* ✨ (Planejado) Animação nos números
* ♿ (Planejado) Melhorias de acessibilidade
